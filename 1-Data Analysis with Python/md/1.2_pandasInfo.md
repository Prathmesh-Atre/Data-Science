# Pandas: Data Analysis and Manipulation

## What is Pandas?
Pandas is a powerful, open-source data manipulation and analysis library for Python. It is built on top of NumPy and provides easy-to-use data structures and data analysis tools.

## Why Do We Use It and Where Is It Used?
- **Purpose:** It is primarily used for working with structured, tabular data (like spreadsheets or SQL tables). 
- **Use Cases:** Data cleaning, data transformation, exploratory data analysis (EDA), and data wrangling. It handles missing data effortlessly and makes reshaping, slicing, filtering, and aggregating data very simple.

## Difference Between NumPy and Pandas
**Why have Pandas when we already have NumPy?**
- **Data Types:** NumPy arrays generally hold homogeneous data (e.g., all numbers of the same type). Pandas DataFrames are designed to hold heterogeneous data (different data types in different columns, such as strings, integers, floats, and dates all in the same table).
- **Labels:** Pandas provides labeled axes (meaningful row and column names), making it much easier to intuitively access and manipulate data without having to remember integer index positions.
- **Functionality:** Pandas provides higher-level functions tailored specifically for real-world messy data, such as handling missing values, merging/joining datasets easily, and robust time-series functionality.

## The 2 Primary Data Structures

### 1. Series
A **Series** is a one-dimensional array-like object that can hold any data type. Think of it as a single column in a table or a sophisticated list with an index.

**Creation Syntax:**
```python
import pandas as pd

# From a simple list
data = [1, 2, 3, 4, 5]
series = pd.Series(data)

# From a dictionary (keys automatically become the index)
data_dict = {'a': 1, 'b': 2, 'c': 3}
series_dict = pd.Series(data_dict)
```

### 2. DataFrame
A **DataFrame** is a two-dimensional, size-mutable, tabular data structure with labeled axes (rows and columns). Think of it as an Excel spreadsheet or an SQL table.

**Creation Syntax:**
```python
# Method 1: From a dictionary of lists
data = {
    'Name': ['Krish', 'John', 'Jack'],
    'Age': [25, 30, 45],
    'City': ['Bangalore', 'New York', 'Florida']
}
df = pd.DataFrame(data)

# Method 2: From a list of dictionaries
data_list = [
    {'Name': 'Krish', 'Age': 32, 'City': 'Bangalore'},
    {'Name': 'John', 'Age': 34, 'City': 'Bangalore'}
]
df2 = pd.DataFrame(data_list)
```

## Different Functions & Methods used in the Notebook

- **Loading Data**
  - `pd.read_csv('filename.csv')`: Loads data from a CSV file directly into a DataFrame.

- **Viewing Data**
  - `df.head(5)`: Returns the first 5 rows of the DataFrame.
  - `df.tail(5)`: Returns the last 5 rows of the DataFrame.

- **Accessing Data**
  - `df['ColumnName']`: Accesses a specific column as a Series.
  - `df.loc[index]`: Accesses a row by its exact label/index.
  - `df.iloc[index]`: Accesses a row by its integer position (0-based indexing).
  - `df.at[row_label, col_label]`: Accesses a specific single scalar value using exact labels. Fast for single elements.
  - `df.iat[row_pos, col_pos]`: Accesses a specific single scalar value using integer positions.

- **Modifying Data**
  - `df['NewColumn'] = [val1, val2, ...]`: Adds a new column to the DataFrame.
  - `df['Age'] = df['Age'] + 1`: Modifies an existing column entirely (Vectorized operations).
  - `df.drop('ColumnName', axis=1, inplace=True)`: Removes a specified column permanently (`axis=1` indicates column).
  - `df.drop(index, inplace=True)`: Removes a specified row permanently (`axis=0` by default).

- **Understanding Data Metadata**
  - `df.dtypes`: Returns the internal data types of each column.
  - `df.describe()`: Generates a highly useful statistical summary of all numerical columns (shows count, mean, std, min, max, and percentiles).

## Overall Executive Summary (Quick Recap)

- **Pandas** is the ultimate Python library for interacting with tabular/spreadsheet-like data. 
- **NumPy vs Pandas:** NumPy is for raw homogeneous math. Pandas is for heterogeneous real-world data, providing labels and rich tools for handling missing and messy data.
- **Key Data Structures:** 
  - **Series:** A 1D column of data.
  - **DataFrame:** A 2D table of data with rows and columns.
- **Core Workflow Recap:** You load data (`read_csv`), inspect it initially (`head`, `describe`, `dtypes`), access what you need (`loc`, `iloc`, `df['col']`), and clean/modify it (adding columns, mathematical operations, `drop`).
