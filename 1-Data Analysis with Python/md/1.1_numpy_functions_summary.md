# NumPy Functions and Attributes Summary

Based on the `numpy.ipynb` notebook, here is a simplified explanation of the different functions and attributes used, along with their basic syntax and purpose.

## Array Creation and Manipulation

- **`np.array()`**
  - **Use:** Creates a NumPy array from a regular Python list or tuple.
  - **Syntax:** `arr = np.array([1, 2, 3])`

- **`np.arange()`**
  - **Use:** Creates a 1D array with evenly spaced numeric values within a specified interval.
  - **Syntax:** `np.arange(start, stop, step)` (e.g., `np.arange(0, 10, 2)`)

- **`np.ones()`**
  - **Use:** Creates a new array of a specified shape filled entirely with `1.0`.
  - **Syntax:** `np.ones((rows, columns))` (e.g., `np.ones((3, 4))`)

- **`np.eye()`**
  - **Use:** Creates an identity matrix (a 2D square array with ones on the main diagonal and zeros everywhere else).
  - **Syntax:** `np.eye(n)` where `n` is the number of rows/columns. (e.g., `np.eye(3)`)

- **`arr.reshape()`**
  - **Use:** Changes the shape of an array without changing its containing data.
  - **Syntax:** `arr.reshape(rows, columns)` (e.g., `arr.reshape(1, 5)`)

---

## Array Attributes
These are properties of an array that describe its metadata. They do not require parentheses.

- **`arr.shape`**
  - **Use:** Returns a tuple representing the dimensions of the array (number of rows, number of columns).
  - **Syntax:** `print(arr.shape)`

- **`arr.ndim`**
  - **Use:** Returns the number of dimensions (axes) of the array (e.g., 1 for a 1D array, 2 for a 2D matrix).
  - **Syntax:** `print(arr.ndim)`

- **`arr.size`**
  - **Use:** Returns the total count of elements inside the array.
  - **Syntax:** `print(arr.size)`

- **`arr.dtype`**
  - **Use:** Returns the data type of the elements in the array (e.g., `int32`, `float64`).
  - **Syntax:** `print(arr.dtype)`

- **`arr.itemsize`**
  - **Use:** Returns the memory size (in bytes) of each individual element in the array.
  - **Syntax:** `print(arr.itemsize)`

---

## Mathematical & Universal Functions
These functions perform element-wise mathematical operations on the entire array at once (Vectorized operations).

- **Arithmetic Operators (`+`, `-`, `*`, `/`)**
  - **Use:** Performs basic math operations element-by-element between arrays of the same shape.
  - **Syntax:** `arr1 + arr2`, `arr1 * arr2`

- **`np.sqrt()`**
  - **Use:** Calculates the square root of each element in the array.
  - **Syntax:** `np.sqrt(arr)`

- **`np.exp()`**
  - **Use:** Calculates the exponential value ($e^x$) for every element.
  - **Syntax:** `np.exp(arr)`

- **`np.sin()`**
  - **Use:** Calculates the trigonometric sine of each element.
  - **Syntax:** `np.sin(arr)`

- **`np.log()`**
  - **Use:** Calculates the natural logarithm of each element.
  - **Syntax:** `np.log(arr)`

---

## Statistical Functions
Used to find statistical metrics for the data in an array.

- **`np.mean()`**
  - **Use:** Calculates the arithmetic mean (average) of all elements.
  - **Syntax:** `mean_val = np.mean(data)`

- **`np.median()`**
  - **Use:** Finds the median (exact middle value) of the array elements.
  - **Syntax:** `median_val = np.median(data)`

- **`np.std()`**
  - **Use:** Computes the standard deviation (a measure of data spread).
  - **Syntax:** `std_dev = np.std(data)`

- **`np.var()`**
  - **Use:** Computes the variance of the array elements.
  - **Syntax:** `variance = np.var(data)`

---

## Indexing, Slicing & Logical Operations

- **Indexing and Slicing (`arr[start:end]`)**
  - **Use:** Accesses specific elements or subsets of an array.
  - **Syntax:**
    - Access a single element: `arr[0][0]` or `arr[0, 0]`
    - Slice rows and columns simultaneously: `arr[1:, 1:3]` (Grabs rows from index 1 extending to the end, and columns from index 1 up to but excluding 3).

- **Logical Selection / Masking**
  - **Use:** Filters elements in an array based on conditions using boolean statements.
  - **Syntax:** `data[(data >= 5) & (data <= 8)]` (Filters values that are greater than or equal to 5 AND less than or equal to 8).

---

## Overall Summary

**What is NumPy?**
NumPy (Numerical Python) is a foundational library for scientific computing in Python. It provides support for high-performance multi-dimensional arrays and matrices.

**What can we use it for?**
It is primarily used for performing fast mathematical and logical operations on large sets of data. It is a critical tool for data analysis, machine learning, and numerical mathematics because of its speed and efficiency compared to standard Python lists.

**Key Capabilities:**
- **Functions:** Offers a vast array of mathematical, statistical, and universal functions (like `np.mean()`, `np.exp()`) for element-wise and aggregate computations.
- **Attributes:** Built-in properties (like `.shape`, `.dtype`) allow you to quickly understand the metadata and structure of your data without function calls.
- **Indexing & Slicing:** Provides powerful ways to access, modify, and filter specific portions of data within arrays, including multi-dimensional slicing and boolean masking.
